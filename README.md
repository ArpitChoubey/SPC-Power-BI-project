# 📌 Project Overview

Modern organizations rely on Business Intelligence dashboards for critical business decisions.

This project focuses on validating an enterprise **Power BI Reporting Platform** integrated with the **Swine Connex Portal**, replacing legacy Tableau reporting.

The application enables users to:

- Upload business data securely
- Generate interactive Power BI dashboards
- Monitor Statistical Process Control (SPC)
- Track KPIs
- Analyze trends
- Receive automated email alerts
- Access reports based on user roles

As a QA Engineer, my responsibility was to ensure the platform delivered accurate, secure, and reliable reporting across multiple business workflows.

---

# 🎯 Business Objectives

The primary goals of this project were:

✔ Replace Tableau reports with Power BI dashboards

✔ Deliver real-time KPI reporting

✔ Validate Statistical Process Control (SPC) charts

✔ Verify secure role-based report access

✔ Ensure accurate data visualization

✔ Validate automated email notifications

✔ Improve reporting performance and usability

- Viewing assigned dashboards

### API User

Responsible only for:

- Uploading business data
- Triggering data refresh
