SPC – Power BI Project
📌 Project Overview

SPC – Power BI is an enterprise analytics and reporting solution integrated with the Swine Connex portal to replace Tableau-based reporting. The system enables real-time Statistical Process Control (SPC) monitoring using Power BI, helping stakeholders track KPIs, detect trends, and take proactive decisions.

🎯 Objectives

Replace Tableau reports with Power BI dashboards

Enable real-time SPC control charts and KPI monitoring

Ensure secure, role-based access to reports

Provide automated email alerts on threshold breaches

Improve performance, scalability, and user experience

🧩 Scope of the Project
In Scope

Power BI report integration within web portal

Data upload via Web Portal & APIs

KPI filters, control charts, and SPC rules

Email alert generation based on SPC trends

Role-based access (Admin, UMM users)

Security, performance, and data validation

Out of Scope

Power BI internal workspace administration

Third-party infrastructure failures

Hardware-level testing

👥 User Roles

Admin User – Full access to reports and configurations

UMM User – Restricted, read-only access to assigned KPIs

API User – Data upload only (no report access)

🛠️ Technology Stack

Reporting Tool: Power BI

Backend: SQL Server

Integration: Power BI REST APIs

Portal: Swine Connex Web Portal

Email Alerts: Azure Web Jobs

Data Upload: Excel via API / Web Portal
